# Maison Douce — сайт кондитерской

Сайт премиальной кондитерской в нежной молочно-розовой палитре: каталог десертов, карточки товаров, корзина, поиск и фильтры, «стеклянная» навигация в стиле Apple Liquid Glass и желеобразные анимации кнопок.

**🔗 Живая версия:** https://gothrussia.github.io/site1/

## Возможности

- **Каталог из 28 десертов** в пяти категориях: торты, пирожные, выпечка, круассаны, молочные коктейли. Категории переключаются без перезагрузки страницы.
- **Поиск** по названию (учитывает «ё/е») и **сортировка** по популярности и цене.
- **Подробная карточка товара**: фото, описание, состав, аллергены, выбор размера или веса, количество. Окно закрывается по Escape и кликом мимо, фокус удерживается внутри.
- **Корзина**: добавление, изменение количества, удаление, автоматический подсчёт суммы, счётчик на иконке, сохранение между перезагрузками (localStorage), пустое состояние и демо-оформление заказа.
- **Надёжные изображения**: плавная загрузка с «шиммером», при ошибке или долгой загрузке — тот же снимок в JPG, а если фотохостинг недоступен — локальная иллюстрация.
- **Анимации**: пружинящее «желейное» нажатие кнопок, подъём карточек при наведении, мягкое появление модального окна и корзины. Учитывается `prefers-reduced-motion`.
- **Адаптивность**: компьютер, планшет, телефон (мобильное меню, окно товара открывается снизу, как bottom sheet).
- **Доступность**: семантическая разметка, подписи для кнопок-иконок, управление с клавиатуры, ссылка «Перейти к каталогу».

## Стек

React 19 · TypeScript (strict) · Vite · обычный CSS без UI-библиотек. Из зависимостей — только React.

## Запуск локально

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # сборка в папку dist
```

## Структура

```
src/
  data/products.ts     — все товары: цены, составы, размеры, фото (один массив)
  data/images.ts       — фото главного экрана, «О нас», галереи
  components/          — шапка, главный экран, каталог, карточки, модальное окно, корзина, секции
  hooks/useCart.ts     — логика корзины
  hooks/useOverlay.ts  — Escape, фокус и блокировка прокрутки для окон
  styles/              — палитра, «стекло», анимации, вёрстка
public/fallback/       — запасные иллюстрации на случай, если фото не загрузятся
```
